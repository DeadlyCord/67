# BastiGHG Begleiter (Fabric 1.21.4, client-only)

Bauen:  gradle wrapper && ./gradlew build   (JDK 21)  -> build/libs/*.jar in den mods-Ordner.
Eigene Stimme: .ogg-Dateien nach src/main/resources/assets/bastighg/sounds/voice/ legen
und in sounds.json statt der Villager-Sounds eintragen, z.B. "bastighg:voice/talk1".
Skin: textures/entity/basti.png (64x64) ersetzen.
